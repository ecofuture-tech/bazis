# Bazis 2.21.0

## Added

- **Labels of the Django choices in the OpenAPI schemas of the pydantic models.** A field
  whose type is a subclass of `TextChoices` / `IntegerChoices` (the body or the response of
  a custom action: `work_type: Order.WorkType`) is an `enum` of the values only, and a
  client could not show the labels of the variants. The schema of the type now carries
  `enumDict` (value to `str(label)` in the language of the generation), the key the schemas
  of the model fields already have for their `choices`. A `Literal` and an `Enum` that is
  not a Django `Choices` get none: type the variants of a body by the `TextChoices` of the
  model. The generator of the JSON schema of FastAPI is replaced by a subclass in
  `bazis.core.utils.fastapi_monkey_patch`, like the other patches of the core.

- **A public route declares optional authentication in the OpenAPI.** A route declared
  `public=True` has `security: [{}]` in its operation; FastAPI extends the `security` that
  the authentication dependency of a package gives (`OAuth2PasswordBearer(auto_error=False)`
  makes it required on every operation) by it, so the result is
  `[{OAuth2PasswordBearer: []}, {}]`: a client sees that a token is optional. A route that is
  not public is unchanged.

## Upgrading

Nothing is required: the change only adds `enumDict` to the schemas of the types that were
`enum` without labels. A client that reads the schema as a whole (a generated contract) sees
the new key, and every public operation has the `security` entry; to have labels for a body that uses a `Literal`, type it by the `TextChoices`
of the model.
