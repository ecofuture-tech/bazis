# Bazis 2.4.1

## Security

- **`bazis_introspect` and `bazis.core.introspect.settings_info()` showed some secrets.**
  Only the names whose last word was a secret word were hidden, so for example
  `OPTIONS.sslpassword` of a database, `api_keys`, `apikey`, `private_key_pem`,
  `connection_string` (with `AccountKey=` of a storage) and the `Authorization` headers
  were shown, and a URL password containing `@` was hidden only up to that character. These
  facts go to AI agents (bazis-mcp sends them to the model). Now a name is secret if it
  contains `SECRET`, `PASSWORD`, `PASSWD`, `TOKEN`, `CREDENTIAL`, `PRIVATE`, `APIKEY`,
  `API_KEY`, `ACCESS_KEY`, `ACCOUNTKEY`, `CONNECTION_STRING` or `AUTHORIZATION`, or ends
  with `KEY`, `KEYS`, `PASS`, `DSN` or `AUTH` (the Django settings
  `AUTH_PASSWORD_VALIDATORS`, `PASSWORD_HASHERS` and `PASSWORD_RESET_TIMEOUT` stay
  visible); `Bearer`, `Basic` and `Token` credentials are hidden in any value.

## Changes

- New `bazis.core.introspect.check_messages(deploy=False)`: the messages of the system
  checks as dictionaries, as `manage.py bazis_doctor --json` prints them (the command uses it).
- A docstring of `bazis.core.routes_abstract.initial` had an invalid escape sequence
  (a `SyntaxWarning` on Python 3.12+).
