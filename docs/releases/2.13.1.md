# Bazis 2.13.1

## Fixes

- **`calc_property` accepts a callable that returns the field.** Its signature always
  allowed `Callable[[], FieldCalc]` (`lambda: FieldAnnotate(source=..., query=Subquery(...))`,
  for an expression that needs the loaded models, such as a queryset or a model declared
  later in the module), but the decorator kept the callable as is: the validation of the
  route query read `field_calc.context` of the function (`AttributeError: 'function'
  object has no attribute 'context'`), and a `DependsCalc` argument or a relation returned
  by the callable were not prepared either. The declarations are now kept in
  `calc_cached_property.fields_declared`; `fields_calc` calls the callables
  (`FieldDynamic` is one) and normalizes the fields on its first use, and every reader
  (the route query and its validation, `as_filter`, `DependsCalc`) gets the result.

## Upgrading

Nothing to change. `fields_calc` of a calculated property is computed on the first use
instead of at the declaration of the class; code that assigned it directly keeps working.
