# bazis 2.17.1

## Fixes

- **`SchemaField` and `CallableContext` are hashable.** Their `__hash__` returned a string,
  so hashing them (a set or a dict key) raised `TypeError`. `SchemaField` now hashes the
  name, which agrees with `__eq__` (equal fields have equal names, and a field equals its
  name); `CallableContext` hashes its class path and attribute.
- **Empty relationships requests are checked.** `POST` and `DELETE` of
  `/{item_id}/relationships/{field}/` with `{"data": []}` answered 204 without taking the
  item, so a missing item was not a 404 and the access checks were skipped. They now run the
  same checks as a request with objects (404 for a missing item, 403 for a relationship
  the user cannot write) and then change nothing. `{"data": null}` stays a no-op, and `{"data": []}` on a to-one relationship is now
  refused as an invalid body (422) instead of answered with 204.
