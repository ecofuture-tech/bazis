# bazis 2.15.1

## Docs

- **Translations of the packages in the project.** `bazis.W004` (two installed packages
  translate a msgid differently) and `bazis.W005` (a package has no catalog of a language)
  now name the way to fix them. A project translates a package msgid in its own catalog by
  declaring it with `gettext_noop` in a module of the project (for example
  `<project>/translations.py`), so `manage.py bazis_messages make` extracts it (`make`
  drops msgids that are not in the code) and `apply` translates it; the catalog of the
  project wins over the packages. A package without the language is reported to its
  maintainers. The guide (`bazis/core/AGENTS.md`, Translations) has the recipe.
