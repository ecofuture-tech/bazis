# Bazis 2.4.0

## Tools and AI agents

Bazis packages describe themselves for tools and AI agents (see `docs/agents.md`):

- `manage.py bazis_introspect` prints the installed Bazis packages with their manifests,
  the settings (secrets hidden), the JSON:API models and the route classes of the project
  as JSON; `bazis.core.introspect` is its Python API.
- `manage.py bazis_doctor [--deploy] [--json]` runs the system checks, including the checks
  of the packages that need the routes, and fails on errors.
- The core ships `AGENTS.md` (how to build a Bazis project) and `bazis_manifest.toml`;
  `bazis.core.introspect.validate_manifest` verifies the manifest of a package against its
  code.
- New deployment check `bazis.W001`: `ALLOWED_HOSTS` contains `'*'` (the default).
