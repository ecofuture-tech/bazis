# Bazis 2.25.0

## Added

- **The meta of a file next to the file.** An action that answers a file (an export) could
  not give the client anything else: a number of rows or a total to show next to the saved
  file went into a JSON answer with the file in base64, or into a second request. The
  decorators `http_*` take `file_meta=` (a flat Pydantic model: scalars, dates,
  `Optional`, `Literal`, lists and dicts of them): the OpenAPI answer of the route (its
  status, 200 by default) declares the header `X-Bazis-Meta` with the JSON schema of the
  model as it is sent (by alias, its computed fields too); the `responses` the route
  declares win. A model with an enum (also `TextChoices`) or a nested model is a
  `ValueError` of the decorator: their references (`#/$defs/...`) cannot be resolved in the
  OpenAPI document (type an enum as `str`). The new `file_answer(content, filename,
  media_type, meta=None)` (`bazis.core.routes_abstract.initial`) answers the content with
  `Content-Disposition: attachment` and the name of the file (`filename*` for a name that
  is not ASCII) and the meta by alias as JSON in ASCII in `X-Bazis-Meta`; a meta longer
  than 4096 characters raises `ValueError` (the headers of an answer pass through proxies whose
  buffers are a few kilobytes). bazis-front reads the header from the OpenAPI, whatever
  declares it, and shows the properties of the meta in the result of the form of the
  action. Guide: "Custom routes and actions".

## Changed

- **CORS exposes `Content-Disposition` and `X-Bazis-Meta`.** A browser hides from a script
  of another origin the headers of an answer that CORS does not list in
  `Access-Control-Expose-Headers`: a client on another origin than the API
  (`CSRF_TRUSTED_ORIGINS`) saved every downloaded file without its name and could not read
  the meta. The CORS middleware of the application lists both headers.

## Upgrading

Nothing is required. A product whose action answers a file can drop a JSON answer with the
file in base64 for `file_answer` and `file_meta`. The OpenAPI of such an action changes, so
generate the contract of bazis-front again. A reverse proxy in front of the API must pass
the header `X-Bazis-Meta` (nginx passes the headers of the answer unless told otherwise).
